# Security

Please do not report security vulnerabilities on the public GitHub issue tracker. The [Responsible Disclosure Program](https://auth0.com/responsible-disclosure-policy) details the procedure for disclosing security issues.

This repository is a sample. Its in-memory stores, test-agent mode and demo policies are for learning and local testing; read the [production checklist](docs/deploy.md#production-checklist) before using any of it for real.
